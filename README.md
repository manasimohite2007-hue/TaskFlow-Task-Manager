# TaskFlow — Task Manager

A responsive task management web application built using HTML, CSS, and JavaScript.

## Features
- Add, edit, and delete tasks
- Mark tasks as completed
- Search, filter, and sort tasks
- Real-time task analytics
- Weekly activity chart
- Priority and deadline tracking
- Dark and light themes
- Local storage support

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

https://resonant-stardust-8f1d25.netlify.app

## Note
Tasks are saved in each user's browser and do not automatically sync between devices.
